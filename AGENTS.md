# Repository instructions

- Always check for applicable `.editorconfig` files before editing files and follow their formatting rules.
- Use hyphens between words in endpoint paths, for example `/api/cover-crops/cover-crop-emissions`.
- Use plural nouns for endpoint resource paths.
- Use chemical symbols or formulas rather than chemical names in identifiers. Separate each chemical symbol or formula from surrounding words with underscores, preserving its chemical casing and the existing casing of the surrounding words; for example, use `ManureManagement_CH4` instead of `ManureManagementMethane`, `Factor_N2O` instead of `FactorNitrousOxide`, and `NH3_ModelCoefficientUncertainty` instead of `AmmoniaModelCoefficientUncertainty`. Standalone formulas remain unchanged, for example `N2O`.
